# Ứng dụng Android thử nghiệm

Ứng dụng này chỉ gửi khung hình camera đến Face Auth API. Ứng dụng Flutter chính
nằm tại `apps/frontend_student/`.

## Chạy

1. Khởi động Face Auth API.
2. Cài APK và cấp quyền camera.
3. Nhập địa chỉ API HTTPS của máy chủ.
4. Nhập mã truy cập do quản trị viên cấp.

## Build APK

```text
build_mobile_apk.bat
```
