# Backend

## Cài đặt

```powershell
npm install
```

## Chạy

```powershell
npm run start:dev
```

## Kiểm thử

```powershell
npm run test
npm run test:e2e
```

Backend cần các biến môi trường trong `.env`. Sao chép từ `.env.example` và
thay bằng thông tin database, khóa JWT và khóa Face Auth của môi trường đang chạy.
